# Kit Hotspot WiFi Soldamaq

Mockup visual para apresentação do piloto de captive portal.

Base visual usada:

- Site oficial da Soldamaq: amarelo/preto, varejo técnico, ferramentas, construção, EPI e posicionamento "A Mais Profissional".
- Fluxo real do portal: LGPD, cadastro, OTP WhatsApp, incentivo de avaliação Google e liberação UniFi.

Arquivos:

- `index.html`: prancha com as quatro telas.
- `styles.css`: identidade visual e phone mockups.
- `soldamaq-hotspot-kit.svg`: arte vetorial 16:9 para proposta.
- `soldamaq-hotspot-kit.svg.png`: preview em PNG.
- `soldamaq-hotspot-kit.pdf`: PDF de 1 pagina pronto para envio ao cliente.

Como abrir:

```bash
open index.html
```
